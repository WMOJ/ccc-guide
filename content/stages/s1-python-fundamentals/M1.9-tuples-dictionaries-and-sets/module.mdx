Lists hold values in order and find them again by position. Many CCC problems need something else. You might pair two values together, look a value up by name, or ignore every repeat. This lesson covers three more ways Python groups values: the tuple, the dict, and the set.

A tuple groups values with parentheses, such as `(3, 4)`. You have already used the shape: `a, b = ...` unpacks a tuple's values into separate names.

## Why a set checks membership quickly

Checking whether a value is in a list means comparing it with one element after another. A list of a million numbers may take a million comparisons to say no. A set answers in about one step however many values it holds.

## Using a tuple as a dict key

A dict key has to be a value Python can hash, which roughly means it cannot change after it is stored. A list can change, so it cannot be a key. A tuple never changes once built, so it can. That is why a pair such as `(row, col)` works as one value in a set or as a dict key.

<Code file="examples/visited_cells.py" showOutput caption="Remembering which grid cells have been seen, one (row, col) tuple each" />

`visited.add((row, col))` stores the whole pair. The test `(row, col) in visited` checks the row and column together, which is the only way to identify a cell. A dict works the same way: `distances[(row, col)] = 3` pairs a whole coordinate with a value.

## Common mistakes with dicts and sets

Reading `d[key]` for a key that was never stored raises a `KeyError` and stops the program. Use `.get(key, default)` whenever a key might be missing, as the vote counter does. Use plain `d[key]` only when you are sure the key is there.

Looping with `for k in d:` walks the keys, not the values and not the pairs. Use `d.values()` for the values. Use `d.items()` for each key and value together, which saves writing `d[k]` inside the loop.

A set or a set comprehension silently throws away repeats. If the order or the count of repeats matters, keep a list. Use a set only when repeats are noise.

## Recap

A tuple pairs values and can be a key. A dict looks values up by key, and `.get()` with a default counts without a `KeyError`. A set removes duplicates and answers membership in one step. The three problems below all look values up by key or check them against a small set of rules.
