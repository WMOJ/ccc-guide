Forty minutes into the contest, a problem gives you a grid with an `S` and an `E` and asks for the fewest moves between them. You know the tool: a breadth-first search, from M4.13. What is left is about twenty lines to type correctly, with no file to copy from. C.1 explains why. Code written before the contest cannot come with you, whether it sits in a file, in notes or on a printout. Any template you use is typed fresh inside the three hours. A template you remember cleanly is typed in a minute or two. One you half remember gets rebuilt line by line, and that is where the slips happen.

## Dijkstra

The shortest-path template keeps `(distance, node)` pairs in a `heapq` heap, with a `done` list to skip stale entries. M6.1 labels its nodes with names. This copy uses numbers, so the input is shorter to type and check.

<Code file="examples/template_dijkstra.py" showOutput caption="Shortest distances from node 0 with a heap, skipping entries that are out of date" />

A node can enter the heap several times, each time with a smaller distance, and the older entries still come out later. The line `if done[u]: continue` drops them, and leaving it out makes the loop redo work it has already finished. Only `nd = d + w` changes if a problem charges something other than the edge weight.

## How to practice a template

Open a blank file and type one template without looking at the course version. Run it on the small input from its example and compare with the output shown. If they differ, compare your file to the course version line by line, find the first line that differs, and retype that template from the top. Retyping the whole file matters more than patching one line, because the contest asks for the whole file.

Then change the input to an edge case and check the answer by hand. A blocked grid, a graph with no edges to walk and a single day of rainfall are good ones. Do one template per sitting, and come back to each after a few days.

A template only starts the solution. A problem may number its nodes from 1, use other symbols in its grid or ask for a different total. After typing the shape, reread the statement and edit the marked part. Your time then goes to that part.
